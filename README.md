# Server Performance Stats Script

A simple Bash script (`server-stats.sh`) to analyze basic server performance stats on any Linux server.

## Features
- Total CPU usage
- Total Memory usage
- Total Disk usage
- Top 5 processes by CPU usage
- Top 5 processes by Memory usage
- System overview (OS, uptime, load average)
