# Server Performance Stats

This repository contains my solution to the [Server Performance Stats Challenge](https://roadmap.sh) on roadmap.sh.

## Project URL
https://roadmap.sh/projects/server-stats

## Features
- Total CPU usage
- Total Memory usage (Free vs Used with percentages)
- Total Disk usage (Free vs Used with percentages)
- Top 5 processes by CPU usage
- Top 5 processes by Memory usage
- System overview (OS version, uptime, load average, logged-in users)

## How to Run
1. Make the script executable:
   ```bash
   chmod +x server-stats.sh
   ```
2. Run the script:
   ```bash
   ./server-stats.sh
   ```
